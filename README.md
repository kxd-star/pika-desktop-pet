# Pika Desktop Pet

一个常驻 Windows 桌面右下角的 WPF 真透明皮卡丘桌宠。

## 当前功能

- WPF 真透明悬浮窗口，高清边缘，不占任务栏，空白区域鼠标穿透
- 六种状态演出：待机、开心、触碰、思考、说话、困倦
- 所有动画只使用等比缩放、位移和旋转，不会拉伸或重画皮卡丘
- 呼吸浮动、开心跳跃、电光粒子、触碰抖动、思考气泡、说话节奏和困倦动画
- 无操作时约每 12 秒自然穿插状态演出；状态切换时显示短暂状态提示
- 鼠标触碰时展示 20 条轮换语录，一轮内不重复
- 点击宠物打开 WPF 圆角阴影聊天面板
- 中文 / English 对话模式切换
- AI API 聊天，当前适配 DeepSeek，后续可替换为其他模型服务
- 聊天输入会先经过本地危机识别，再决定是否进入普通 AI 对话
- 支持 R1/R2/R3 风险分流：低风险先确认安全，中高风险直接展示现实求助话术
- 聊天面板和右键菜单提供“求助 / Help”入口，可快速查看紧急帮助提示
- 普通对话提示词已调整为情绪陪伴风格：接住情绪、简短复述、邀请一个小动作
- 对话框支持滚动翻阅当前会话；聊天历史默认不落盘，可在右键菜单主动开启加密保存或清空历史
- AI 连接失败时自动使用更自然、多样的本地兜底回复
- 拖拽移动；右键菜单退出
- 优先加载本地 `assets/pikachu.png`，不存在时使用本地状态图兜底，再尝试在线加载透明高清素材

## 心理陪伴边界

这个 MVP 只做日常情绪陪伴、自助稳定和危机分流，不提供医疗诊断、治疗、用药建议，也不能替代心理咨询师、医生或紧急服务。

如果用户表达可能正在伤害自己或别人，桌宠会停止普通陪聊，优先提示联系现实中的人、当地紧急服务或危机热线。

## 构建

在 Windows PowerShell 中运行：

```powershell
.\build.ps1
```

构建产物为项目根目录下的 `DesktopPetMVP.exe`。

如果桌宠正在运行，构建脚本默认不会强制关闭它。需要自动关闭同名进程时显式运行：

```powershell
.\build.ps1 -KillRunning
```

运行构建和风险识别测试：

```powershell
.\build.ps1 -RunTests
```

## 配置 DeepSeek

```powershell
setx DEEPSEEK_API_KEY "your-key"
setx DEEPSEEK_MODEL "deepseek-chat"
```

设置完成后重新启动桌宠。

## 使用

- 鼠标碰到宠物：展示一条随机反馈语
- 单击宠物：打开或关闭聊天气泡
- 拖拽宠物：移动位置
- 聊天气泡顶部：切换中文 / English
- 聊天气泡顶部“求助 / Help”：查看紧急帮助提示
- 右键宠物 → 紧急帮助 / Crisis help：查看紧急帮助提示
- 右键宠物 → 开启保存聊天历史 / Save chat history：主动开启加密本地历史
- 右键宠物 → 清空聊天历史 / Clear history：删除新旧本地聊天记录
- 右键宠物：打开聊天或退出
- 右键宠物 → 预览六种形态：手动查看每套动作，单次展示 6 秒
- 预览状态会锁定展示，不会被自动待机提前覆盖
